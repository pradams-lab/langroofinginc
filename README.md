# Lang Roofing Inc.

A high-converting, mobile-first business website and lead generation platform built for residential and commercial roofing services.

## ✨ Key Features

- **Mobile-First Architecture:** Fully responsive layout optimized for homeowners searching for emergency roofing repairs or inspections on the go, featuring a sticky mobile bottom call bar for instant conversions.
- **Conversion-Optimized Design:** Strategic visual hierarchy utilizing deep slate navy authority containers and rich accent call-to-action touchpoints.
- **Interactive Sub-Pages:** Dedicated deep-dive service pages (Roof Replacement, Repairs, Inspections) with built-in navigation anchors and frictionless lead capture forms.
- **Visual Portfolios:** Side-by-side before-and-after project transformation galleries showcasing local roofing and structural upgrades.

## 🛠️ Tech Stack

- **Framework:** React / Vite
- **Styling:** Tailwind CSS
- **Hosting & Deployment:** Vercel

## 🚀 Local Development

To run this project locally for development or customization:

```bash
# Clone the repository
git clone [https://github.com/your-username/lang-roofing.git](https://github.com/your-username/lang-roofing.git)

# Navigate to the project directory
cd lang-roofing

# Install dependencies
npm install

# Run the development server
npm run dev
